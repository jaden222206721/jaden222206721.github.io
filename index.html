User Stories & Tasks

User stories describe project requirements from the perspective of the people involved in using or benefiting from the project. They help the team understand what needs to be achieved and break larger requirements into manageable tasks.

ActiveEdge User Stories

User Story 1 – Business Case Presentation

As an ActiveEdge project team, we want to convert the approved business case into a professional presentation so that we can communicate our business idea clearly to the class.

Tasks:
  • Prepare a 14-slide presentation outline.
  • Map the slides to the business case sections.
  • Prepare the title, agenda and team roles slides.
  • Convert the value proposition and problem definition into slides.
  • Assign speaking sections to team members.
  • Rehearse and present the completed presentation.

User Story 2 – Team Rehearsal

As a project team, we want to rehearse our presentation so that each member can deliver their assigned section confidently and within the time limit.

Tasks:
  • Allocate presentation sections.
  • Schedule a team rehearsal.
  • Practise individual speaking sections.
  • Review the presentation and make final improvements.

User Story 3 – Trello Taskboard Validation

As a project team, we want to present our Trello taskboard to the lecturer so that our Agile workflow and task management can be reviewed and validated.

Tasks:
  • Prepare a walkthrough of the Trello board.
  • Show task allocation and progress tracking.
  • Explain sprint planning and task organisation.
  • Present the board to the lecturer.
  • Record and review feedback.

User Story 4 – Prototype Design

As a project team, we want to explore different design approaches and create wireframes so that we can choose a suitable interface for the ActiveEdge platform.

Tasks:
  • Research UI/UX design patterns.
  • Discuss possible design approaches.
  • Map user journeys.
  • Create low-fidelity wireframes.
  • Evaluate design options against user needs.
  • Select a suitable design approach.

User Story 5 – Website Development

As an ActiveEdge project team, we want to move from the static prototype towards a functional website so that the project can provide a more complete digital experience.

Tasks:
  • Establish the website codebase and folder structure.
  • Develop the main website layout and navigation.
  • Improve responsiveness across different screen sizes.
  • Include the brand logo and product images.
  • Plan database structure and API endpoints.
  • Coordinate front-end, back-end and content tasks.
  • Perform integration checks.

My Contribution

My documented individual contributions included completing the problem definition and 5W marketing strategy, reviewing and editing presentation content, participating in the presentation rehearsal and presenting my assigned slides. I also took part in the Trello walkthrough and subsequent project feedback activities.

My Reflection

Creating and working with user stories helped me understand how large project requirements can be divided into smaller tasks. Instead of looking at the project as one large piece of work, we could focus on specific activities and complete them step by step.
